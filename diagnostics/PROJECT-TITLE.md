# プロジェクトを畳んだ際の限定診断

目的：現在チャットのリンクが存在／可視か、対応するアクションが一意か、上部のメニューボタンに動的ARIAで関連するメニューがあるかを確認する。正規の代替UIがあることはまだ実証していない。診断は候補を報告するだけでクリックしない。

1. 対象チャットで `project-title.js` 全文をDevTools Consoleへ貼り付けて実行する。
2. 10秒以内にページへ戻る。まずプロジェクトを畳んだ状態で待つ。10秒後に1回だけ採取する。
3. Consoleで次を実行して結果をコピーする。

```js
copy(JSON.stringify(window.__ctcProjectDiagnostic, null, 2))
```

次にプロジェクトを再展開して同じ手順で採取する。タイトル文字列・チャットID・本文・入力値・アカウント情報は出力しない。展開／折りたたみ以外のクリックは不要。

上部に「現在のチャット」の名前変更ができるメニューが利用者側で見つかった場合だけ、再度診断を開始し、そのメニューを手動で開いたまま10秒待つ。Renameを選ぶ必要はない。対応候補とARIA関連を採取し、採取後はメニューを閉じても結果は保持される。リンクなしの代替操作を製品へ登録するには、この対応関係の追加確認が必要。

状況確認：
```js
window.__ctcProjectDiagnostic
```
停止：
```js
window.__ctcProjectStop?.()
```
結果破棄：
```js
window.__ctcProjectStop?.(); delete window.__ctcProjectDiagnostic; delete window.__ctcProjectStop;
```

通信、入力変更、保存、自動展開なし。継続監視なし。タイマーとpagehideリスナーは終了・停止時に解除。各実行で以前の待機を止め、結果を置換する。
