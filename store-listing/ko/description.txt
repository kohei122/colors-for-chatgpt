채팅마다 원하는 색을. 🎨

■ 사용 방법
① 설치 후 열려 있는 ChatGPT 페이지를 새로고침하세요.
② 확장 프로그램 아이콘을 클릭하세요.
이렇게 하면 해당 채팅에 색 띠와 제목이 표시됩니다.
띠의 색상·표시 메뉴에서 색과 크기를 조정할 수 있습니다.

■ 주요 기능
• 채팅마다 띠와 테두리 색 설정
• 화면 상단에 채팅 이름을 크게 표시
• 띠 높이, 테두리 두께, 글자 크기와 색 조정
• 띠의 채팅 이름을 클릭하여 ChatGPT의 실제 이름 편집
• 띠의 ×로 숨기거나 팝업에서 전체 또는 채팅별로 ON/OFF 전환
• 채팅별 설정 저장 및 동일한 브라우저 프로필의 다른 탭과 공유
• 확장 프로그램 인터페이스 7개 언어 지원

※ 채팅 이름 편집은 ChatGPT의 표시 언어가 일본어 또는 영어일 때만 지원됩니다. 대상 채팅이 사이드바에 표시되어 있어야 하며, 해당 폴더가 접혀 있으면 편집할 수 없습니다.

■ 지원 환경
ChatGPT 공식 웹 버전(chatgpt.com)을 지원합니다.
데스크톱 앱, 모바일 앱, 다른 AI 서비스는 지원하지 않습니다.
새 채팅은 대화를 시작하여 채팅 ID가 부여된 후 사용할 수 있습니다.
ChatGPT의 화면 변경으로 일부 기능을 사용할 수 없게 될 수 있습니다.

■ 개인정보 보호
대화 본문이나 메시지 입력란의 내용을 수집·저장하지 않으며, 확장 프로그램 자체의 외부 서버로 데이터를 전송하지 않습니다.
설정은 브라우저에 저장하며, 채팅 ID로 채팅을 식별합니다.
화면 조정과 이름 변경을 위해 페이지 내 요소를 읽고 조작합니다.

소스 코드는 GitHub에 공개되어 있어 누구나 확장 프로그램의 동작 방식을 확인할 수 있습니다.
